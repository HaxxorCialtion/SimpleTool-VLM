# SimpleTool-VLA

**Coming soon.**

This track will connect SimpleTool-VLM perception and positional tool heads to
vision-language-action interfaces and embodied-control environments. It will
be released separately from the validated VLM protocol and will include task
prompts, action schemas, simulator configuration, and reproducible evaluation
receipts.

The existing prompt-assisted Panda red-cube grasp preview is not an autonomous
VLA claim: its prompt supplied geometry, grasp order, heights, gripper values,
and a calibrated RGB-D localization tool. A future release will state clearly
which information comes from pixels, tools, prompts, and learned policy.
